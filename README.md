# บัญชีกลุ่มงานบริการด้านปฐมภูมิ — คู่มือติดตั้ง

แอปบันทึกรายรับ–รายจ่าย ติดตั้งบนมือถือได้ (PWA) ใช้ Google Sheets เป็นที่เก็บข้อมูล ทุกคนในทีมเห็นข้อมูลชุดเดียวกัน ไม่ต้องมีบัญชี Claude

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าแอป |
| `manifest.json`, `sw.js`, `icon-*.png`, `apple-touch-icon.png` | ทำให้ติดตั้งเป็นแอปและเปิดได้ตอนสัญญาณหลุด |
| `Code.gs` | โค้ดฝั่ง Google Sheets (ไม่ต้องอัปโหลดขึ้น GitHub) |

---

## ขั้นที่ 1 · สร้างที่เก็บข้อมูลใน Google Sheets (ประมาณ 5 นาที)

1. เปิด Google Sheets ใหม่ ตั้งชื่อ เช่น `บัญชีปฐมภูมิ 2570`
2. เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิม แล้ววางเนื้อหาไฟล์ `Code.gs` ทั้งหมด
3. แก้บรรทัด `const TEAM_PIN = 'เปลี่ยนรหัสนี้';` เป็นรหัสทีม เช่น `'482915'` แล้วกดบันทึก (💾)
4. เลือกฟังก์ชัน **setup** ที่แถบด้านบน แล้วกด **เรียกใช้** → อนุญาตสิทธิ์ตามที่ Google ถาม
   (ถ้าขึ้นว่า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด ขั้นสูง → ไปที่โปรเจกต์)
   ระบบจะสร้างแท็บ **รายการ** และ **ยอดยกมา** ให้
5. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
6. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`) เก็บไว้

> ถ้าแก้โค้ด `Code.gs` ภายหลัง ต้องกด **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข (✏️) → เวอร์ชัน: เวอร์ชันใหม่** ลิงก์เดิมจึงจะได้โค้ดใหม่

## ขั้นที่ 2 · เอาหน้าแอปขึ้น GitHub Pages

1. ที่ github.com กด **New repository** ตั้งชื่อ เช่น `primary-ledger` เลือก **Public**
2. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมด **ยกเว้น `Code.gs`** ขึ้นไป → Commit
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main / (root)** → Save
4. รอ 1–2 นาที แอปจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/primary-ledger/`

## ขั้นที่ 3 · เปิดใช้และติดตั้งบนมือถือ

1. เปิดลิงก์ GitHub Pages บนมือถือ → แอปจะพาไปหน้า **ตั้งค่า**
2. ใส่ **ลิงก์ Web App** จากขั้นที่ 1, **รหัสทีม** และ **ชื่อผู้บันทึก** → กด *บันทึกและทดสอบการเชื่อมต่อ*
3. ติดตั้งเป็นแอป
   - **Android (Chrome):** กดปุ่ม *ติดตั้งแอป* ในหน้าตั้งค่า หรือเมนู ⋮ → *ติดตั้งแอป*
   - **iPhone (Safari):** ปุ่มแชร์ → *เพิ่มไปยังหน้าจอโฮม*
4. ส่งลิงก์ GitHub Pages + ลิงก์ Web App + รหัสทีม ให้เพื่อนในกลุ่มงาน แต่ละคนตั้งค่าในเครื่องตัวเองครั้งเดียว

## ใช้งาน

- **ภาพรวม:** ยอดยกมา รายรับ รายจ่าย คงเหลือ และกราฟรายเดือน เลือกปีงบ 2569–2579 หรือรายเดือนได้
- **บันทึก:** เลือกรายรับหรือรายจ่าย กรอกวันที่ เลขที่เอกสาร หมวด แหล่งเงิน รายละเอียด จำนวนเงิน
- **รายการ:** ค้นหา กรอง แก้ไข ลบ และดูยอดคงเหลือสะสมทีละรายการ
- **ส่งออก CSV:** เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน
- **สัญญาณหลุด:** บันทึกต่อได้ รายการจะขึ้นว่า "รอส่ง" และส่งขึ้น Google Sheets เองเมื่อกลับมาออนไลน์
- ข้อมูลทั้งหมดดูหรือแก้ตรงใน Google Sheets ได้ (แท็บ **รายการ**) — ห้ามแก้คอลัมน์ *รหัส* และอย่าลบแถวที่ 1–2

## ความปลอดภัย

- ใครก็ตามที่มีทั้ง **ลิงก์ Web App และรหัสทีม** จะอ่านและแก้ข้อมูลได้ ให้แชร์เฉพาะคนในกลุ่มงาน
- ถ้ามีคนย้ายออก ให้เปลี่ยน `TEAM_PIN` ใน `Code.gs` แล้ว deploy เวอร์ชันใหม่ (ขั้นที่ 1 หมายเหตุ) และแจ้งรหัสใหม่ในทีม
- Google Sheets ต้นฉบับอยู่ในบัญชีของผู้สร้าง แชร์ไฟล์ชีตให้หัวหน้ากลุ่มงานไว้ด้วยเพื่อสำรอง

## ปรับหมวดหมู่ / แหล่งเงิน

แก้ใน `index.html` บรรทัดที่ขึ้นต้นด้วย `const CATS=` และ `const FUNDS=` แล้วอัปโหลดทับใน GitHub
เมื่ออัปเดตไฟล์แอป ให้เปลี่ยน `VERSION` ใน `sw.js` (เช่น `v1` → `v2`) เพื่อให้มือถือที่ติดตั้งไว้โหลดเวอร์ชันใหม่
